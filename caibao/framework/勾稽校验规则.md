# 勾稽校验规则（Cross-Statement Check）

> 这是整个框架的**第一道关**，也是唯一一道"不需要判断、只需要计算"的关。
>
> 逻辑起点：利润表是**意见**，现金流量表是**证词**，资产负债表是**事实**。
> 三张表之间如果对不上，后面所有比率分析都是在错误的地基上盖楼。

## 一、两种勾稽，不能混为一谈

| 类型 | 定义 | 容差 | 不平意味着什么 |
|---|---|---|---|
| **硬勾稽** | 会计恒等式，只要报表编制正确就必然成立 | 1%~2% | **报表本身有错**。停下，别往下分析 |
| **软勾稽** | 含估算假设的等式（税率、口径、汇率、合并范围） | 20%~80% | 只作**提示**，需人工核对口径，不能直接定罪 |

**实测结论**（中远海能/茅台/宁德/格力/神华 五个标的历史 12 期）：
硬勾稽 6 项全部 0.0% 通过；软勾稽才是差异的主要来源。所以——

> **看到软勾稽超容忍不要慌，先问"这个行业的税率/结算模式/外币敞口是什么样的"；
> 看到硬勾稽不平要慌，那说明三张表内部矛盾。**

## 二、硬勾稽（六条，必须平）

| 代码 | 等式 | 数据字段 | 容差 |
|---|---|---|---|
| CK-01 | 资产总计 = 负债合计 + 所有者权益合计 | `TOTAL_ASSETS` / `TOTAL_LIABILITIES` / `TOTAL_EQUITY` | 1% |
| CK-02 | 所有者权益合计 = 归母权益 + 少数股东权益 | `TOTAL_EQUITY` / `TOTAL_PARENT_EQUITY` / `MINORITY_EQUITY` | 1% |
| CK-03 | 期末现金及现金等价物 = 期初 + 现金净增加额 | `END_CCE` / `BEGIN_CCE` / `CCE_ADD` | 1% |
| CK-04 | 现金净增加额 = 经营 + 投资 + 筹资 + 汇率影响 | `CCE_ADD` / `NETCASH_OPERATE` / `NETCASH_INVEST` / `NETCASH_FINANCE` / `RATE_CHANGE_EFFECT` | 1% |
| CK-05 | 间接法经营现金流 = 直接法经营现金流 | `NETCASH_OPERATENOTE` / `NETCASH_OPERATE` | 2% |
| CK-06 | 利润总额 − 所得税费用 = 净利润 | `TOTAL_PROFIT` / `INCOME_TAX` / `NETPROFIT` | 2% |

**CK-05 最容易被忽略但最有用**：现金流量表补充资料（间接法）是从净利润倒推经营现金流，
它是三张表的**总枢纽**。上市公司极少改这一栏——改动它需要同时改动净利润、折旧、
应收应付、存货等十几处，牵一发动全身。所以间接法与直接法对不上，是**极强的人为干预信号**。

## 三、软勾稽（四条，只作提示）

### CK-07 收入含金量（最重要的一条软勾稽）

```
销售收现 ≈ 营业收入 × (1 + 适用增值税率)
            − (应收票据及账款期末 − 期初)
            + (合同负债期末 − 期初)
```

- 字段：`SALES_SERVICES` / `OPERATE_INCOME` / `NOTE_ACCOUNTS_RECE` / `CONTRACT_LIAB`
- 容差：20%（对不上先怀疑口径，不要直接说造假）
- **税率必须按行业设**：
  - 制造业、消费品、零售 → 13%
  - 交通运输（国际航线）、部分公用事业 → **0%**（免增值税）
  - 建筑、不动产租赁、电信 → 9%
  - 现代服务、软件 → 6%
- 脚本参数：`--vat 0` / `--vat 0.09` / `--vat 0.06`
- 对比去年同期而非上一季度，避开季节性

> 若税率正确仍然对不上（>20%），才进入"收入虚增 / 回款造假 / 跨期调节"的怀疑区间。
> 参考案例：某公司营收 10 亿（税率 13%）、应收增 2 亿、预收增 0.5 亿，
> 理论上收现应为 9.8 亿，实际披露 6.2 亿，缺口 3.6 亿 → 后续证实营收虚增 3.2 亿。

### CK-08 税费匹配

```
(支付的各项税费 − 收到的税费返还) ≈ 所得税费用 + 税金及附加
```

- 字段：`PAY_ALL_TAX` / `RECEIVE_TAX_REFUND` / `INCOME_TAX` / `OPERATE_TAX_ADD`
- 容差：**80%**（放得很宽，原因见下）
- 为什么宽：所得税费用是**权责发生制**（含递延所得税），支付税费是**收付实现制**；
  加上留抵退税、汇算清缴时间差，天然偏离 30%~60% 很常见
- 真正的用法不是看缺口，而是看**两个独立比率**：
  - 有效税率 = 所得税费用 / 利润总额（正常 5%~40%，长期异常低且无优惠政策 → 查）
  - 应交税费余额持续攀升而支付税费极小 → 可能是资金链断裂或账外资金调度

### CK-09 资本开支真实度

```
购建固定资产、无形资产和其他长期资产支付的现金
    ≈ (固定资产 + 在建工程 + 无形资产) 期末 − 期初 + 本期折旧摊销
```

- 字段：`CONSTRUCT_LONG_ASSET` / `FIXED_ASSET` / `CIP` / `INTANGIBLE_ASSET` /
  `FA_IR_DEPR` / `IR_DEPR` / `IA_AMORTIZE` / `USERIGHT_ASSET_AMORTIZE`
- 容差：50%
- 为什么会超：资产处置、外币报表折算（如船舶、飞机）、合并范围变动、
  预付工程款未转固、部分投入走"其他非流动资产"
- **更好的替代读法**：直接看 `资本开支 / 折旧摊销` 的比值
  - < 1：在吃老本，未来产能收缩
  - 1~2：维持性投入
  - > 3：激进扩张（配合在建工程占比、行业景气度判断真实性）

### CK-10 权益连续性

```
归母权益期末 ≈ 归母权益期初 + 归母净利润 − 分红
```

- 容差：30%
- 必须放这么宽的原因：**其他综合收益**（外币折算差额、可供出售金融资产公允价值变动）、
  股权激励、可转债转股、少数股东权益变动都不在这条式子里
- 跨国经营、有大量外币资产的公司（航运、航空、有色）必然对不上
- 用途：它是一个"提醒你去翻所有者权益变动表"的信号，不是判据

## 四、判读流程

```
1. 跑硬勾稽 6 条
   ├─ 有任何一条 > 容差 → 🔴 停止分析，先确认报表数据源是否有误
   └─ 全部通过 ↓
2. 跑软勾稽 4 条
   ├─ 全部在容忍度内 → 数据可用，进入比率分析
   └─ 某项超容忍 → 按行业口径解释；解释不通才升级为疑点
3. 看跨期一致性
   └─ 同一项勾稽连续 2 期以上超容忍 → 提级（单期波动多为噪音）
```

## 五、行业适配备忘

| 行业特征 | 最容易误报的项 | 处理 |
|---|---|---|
| 国际航运 / 航空（免增值税、外币敞口大） | CK-07、CK-09、CK-10 | `--vat 0`；CK-09/CK-10 只看趋势不看绝对值 |
| 重资产（电力、煤炭、化工） | CK-09 | 关注 capex/折旧比而非勾稽缺口 |
| 经销商打款模式（白酒、家电） | CK-07 | 合同负债波动大，用去年同期比；收现比季节性强 |
| 高杠杆金融类 | CK-01、CK-06 | 金融企业报表科目不同，本框架规则不完全适用 |
| 并购频繁 | CK-09、CK-10 | 合并范围变动导致必然偏离，需读附注 |

## 六、当前数据下的能力边界

- ✅ 可以做：三表交叉验算、比率计算、跨期趋势、审计意见识别
- ⚠️ 需要人工补：**倒算存款利率**（货币资金造假最硬的证据）——
  东财不提供利息收入明细，需从年报附注手工取"货币资金明细 + 利息收入"
- ⚠️ 需要人工补：**增值税销项/进项明细**、**关联交易明细**、**对外担保与未决诉讼**
  —— 这些只在附注里，需读原文（见下节）
- ❌ 做不到：银企对账、函证、实地核查——任何自动化都无法替代

## 七、附注必须人工扫的三个地方

数字勾稽只能验证"表内自洽"，验证不了"业务真实"。以下三处必须翻附注：

1. **关联方关系及其交易** —— 特别关注无商业实质的资金往来、关联交易占比 > 30%、
   定价是否偏离市场公允价 20% 以上
2. **或有事项与承诺** —— 未决诉讼、对外担保（担保额占净资产比例）、税收争议
   > 典型暴雷：主表四平八稳，附注里写着"为关联方提供了相当于净资产 50% 的连带责任担保"
3. **会计政策与会计估计变更** —— 折旧年限从 10 年拉长到 20 年、坏账计提比例下调、
   研发费用资本化率上升，每一条都是合法调节利润的手段

## 八、证据闭环原则（输出报告时强制）

> **每一个风险结论都必须能回到具体科目和具体数字。禁止输出没有数据出处的推论。**

反面例子：「公司可能存在财务造假风险」——没有出处，等于没说。
正确写法：「2026H1 收现比 0.72（去年同期 1.03），同期应收票据及账款占总资产比重
由 31% 升至 38%，两项背离」——有指标、有数值、有对比期。
