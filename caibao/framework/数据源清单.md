# 数据源路由清单

> 依据用户《金融数据源总控（Finance Data Hub）》图（19 源 · 2026-09-03 巡检）整理，
> 并标注**本框架每个环节该用哪个源**。

## 一、内置通道（零依赖、免注册，已验证）

这是本 skill 的**默认档**，开箱可用，不需要任何 Key：

| 通道 | 用途 | 端点 | 依赖 |
|---|---|---|---|
| 东财 F10 | A股三张表 + 主要指标，50 期历史 | `datacenter.eastmoney.com/securities/api/data/v1/get` | 无（标准库 urllib） |
| 东财行情 | 现价 / 市值 / PE(动态) / PB | `push2delay.eastmoney.com/api/qt/stock/get` | 无 |
| 腾讯行情 | PE(TTM) / PB 兜底（GBK 编码） | `qt.gtimg.cn/q=sh600026` | 无 |

**为什么默认用东财**：`Access-Control-Allow-Origin: *` 已对 `duoyu813-png.github.io` 开放，
所以浏览器端可以直连，不需要后端；返回字段覆盖本框架 90% 的指标需求。
**但有两个硬缺口**：①不给 PE(TTM) ②不给货币资金利息收入明细。

## 四、降级链（务必按序尝试）

```
A股三表：  东财 F10  ──失败──▶  东财 datacenter-web  ──▶  akashare  ──▶  a-stock-data
A股行情：  push2delay ──失败──▶  腾讯 gtimg           ──▶  easy-tdx
美股三表：  edgartools ──▶  yfinance  ──▶  FMP  ──▶  Macrotrends
```

**已踩过的坑（不要重复）：**
- `push2.eastmoney.com` 常连不上 → 必须用 `push2delay.eastmoney.com`
- 东财 F10 响应结构是 `{result:{data:[...]}}`，**不是** `{data:{list}}`
- 东财 F10 的 `filter` 参数**不能先手工 quote 再交给 urlencode**，会双重编码导致返回空
- 腾讯行情是 GBK 编码，Python 用 `.decode('gbk')`，浏览器用 `new TextDecoder('gbk')`
- 东财行情整数需 /100（价格、PE、PB、涨跌幅都是）
- 沪市后缀 `.SH`、深市 `.SZ`、北交所 `.BJ`

## 五、缺口与人工补位

| 需求 | 为什么自动取不到 | 人工方案 |
|---|---|---|
| 货币资金利息收入 | 东财只给货币资金余额，不给利息收入 | 翻年报附注「货币资金」明细算倒算利率 |
| 增值税销项/进项 | 报表只给"支付的各项税费"合计 | 用有效税率与应交税费变动侧面判断 |
| 关联交易明细 | 仅在附注 | 读附注「关联方及关联交易」 |
| 对外担保/未决诉讼 | 仅在附注 | 读附注「或有事项」 |
| 行业叙事空间锚（白酒批价、光伏渗透率等） | 行业专属，无统一接口 | 人工给数；或走 a-stock-data / Wind 行业数据 |

## 六、接入约定

- 本 skill 的 `scripts/caibao.py` **只用内置三通道**，零依赖，任何时候都能跑
- 需要上述其他源时，**优先用 Python 生态同名库**：`pip install akshare yfinance edgartools fredapi` 等
- 装库请装进隔离环境：
  `C:\Users\34970\.workbuddy\binaries\python\envs\default\Scripts\pip.exe install <包名>`
- **不要**因为某个源不可用就编数据。取不到就明确标注"数据缺口"，交给人工
