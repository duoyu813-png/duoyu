# 穿透财报分析框架 · 总纲

> 蒸馏自邹佩轩三本：《穿透财报》（舞弊/调节/三表）、《穿透估值》（DCF/PE/PB/PS）、《穿透叙事》（空间叙事/拍卖机制）。
> 目标：把三本书变成一台**可执行的机器**——输入公司代码，输出一份结构化财报分析报告。

---

## 一、一句话世界观

**不给财报估值，给叙事估值。**

财报的作用是**证伪或证实**叙事，而不是给公司定价。定价权在「叙事」手里——市场买的是**终局**，不是过程。

三条公理：

1. **利润表是一种意见，现金流量表是一种证词，资产负债表才是事实。**
   权责发生制下利润表可调节；判断真实性的切入点永远是资产负债表。
2. **虚增利润归根结底都是虚增资产。**
   三张报表联动配平的刚需下，造假必然在资产端留下痕迹，且痕迹只会越来越大、越来越冷门。
3. **超额收益只能来自叙事的变化。**
   增速是过程，空间是终局；分子（业绩）与分母（估值）消不掉的那一块，才是超额收益。

## 二、四步法总流程

| 步骤 | 名称 | 回答的问题 | 主要工具 |
|---|---|---|---|
| **第 0 步** | 基础事实卡 | 这是一家什么公司？现在多少钱？ | 行情 + 主要指标 |
| **第 1 步** | 引擎 A · 叙事定位 | **股价里埋的是什么故事？** | 估值体系矩阵 + 反推隐含稳态利润 L |
| **第 2 步** | 引擎 B · 三表科目验证 | **故事有没有被财报兑现？** | 三张表科目级扫描 + 勾稽 |
| **第 3 步** | 模块 C · 舞弊识别 | **财报是不是假的？（合理怀疑 + 有罪推定）** | 七类舞弊红旗 |
| **第 4 步** | 模块 D · 合法调节识别 | **财报是不是被"合法地"调过？** | 递延所得税探测器等 |
| **第 5 步** | 叙事匹配度总结 | **故事还成立吗？** | 打分卡 + 开放项 |

**核心闭环**：引擎 A 算出「市场相信什么」→ 引擎 B 检验「财报兑现了什么」→ C/D 判断「证据可不可信」→ 回到 A 判断「叙事是自我延续还是被证伪」。

## 三、第 1 步 · 引擎 A：叙事定位

### 3.1 两套定价机制

| | 空间叙事（应然 · 锚） | 拍卖机制（实然 · 价格形成） |
|---|---|---|
| 本质 | 股价 = 目之所及的所有未来现金流折现 | 股价是交易出来的，由**最乐观资金**定价（A股无做空） |
| 主参数 | m（天花板高度）、r、n | σ²（预期离散度）、x（关注度/流动性） |
| 漂移 | — | `∂y/∂σ² > 0`、`∂y/∂x > 0` 且**二阶导为正**（越算不清、流动性越泛滥，涨得越猛） |

### 3.2 估值体系选型矩阵

| 方法 | 适用 | **失效条件** |
|---|---|---|
| **PE** | 非亏损、非盈亏边缘、业绩波动不大 | ①应收应付周转慢；②资产重且已成沉没成本；③折旧期限与使用寿命偏离大 |
| **EV/EBITDA** | PE 失效时的替代/**初筛** | 自带杠杆（倍数+20%→市值+67%），新租赁准则下使用权资产折旧**不能**加回；**不算目标市值** |
| **PB** | 业绩波动过大/亏损/盈亏边缘，PE 过于敏感 | 轻资产、人力资源为主行业意义小；金融资产+营运资本占比高时净资产失真 → 应剔除后给 PB 再按 1 倍 PB 加回 |
| **PB-ROE** | **同行业内**筛选（禁跨行业） | 四条件缺一不可：行业成熟 / 会计政策一致 / 用重置成本重算折旧 / 资产剩余寿命相当 |
| **PS** | 固定成本极高、边际成本近零、产品标准化（软件）；水电、高速、BOT 等收租类 | 核心假设"扩大收入规模几乎不需要成本"不成立即失效；**销售费用与收入成正比者禁用** |
| **DCF** | 无可比公司、核心假设重大变化、板块性机会；极端高估/低估时定止盈点 | 输出对参数**非线性**敏感；算不出 50%~100% 空间，所谓目标涨幅可能都是计算误差 |

**跃迁路径**：初创看 PS → 成长看 PE → 周期亏损看 PB、盈利看 PE → 稳定看 PB-ROE。
**跃迁点往往是超额收益或亏损的来源。**

### 3.3 反推「市场隐含的稳态利润 L」（核心动作）

**路径 1（当前有业绩、匀速增长）**

1. 固定 `r = 10%`（A股权益口径默认，长期均值回归，不受无风险利率影响）。
2. 由当前 PE(TTM) **反查**隐含天花板倍数 m，得 `L = m × 当前归母`。
3. 反查锚点（r=10%, n=10年）：`PE 15.3→m=2`；`20→3`；`28.8→5`；`48.6→10`；`66.3→10倍+2%永续`。
4. **剥离分母端**：用 `个股PE(TTM) / 沪深300 PE(TTM)` 过滤折现率变化，剩余变动即分子端（隐含天花板）的相对变化。

**路径 2（当前无业绩/微利，等差增长）**

5. `L = 当前市值 / 市值速算倍数`。r=10% 时：5 年到达 → **8.3**；10 年到达 → **6.8**。
6. 修正：若权益现金流远低于净利润 → **调小**折算倍数（即算出的 L 更大）。

**路径 3（倒算原则）**：固定分歧小的两个参数，倒算分歧大的那个。
成长股 → 倒算增速持续时间；类债股 → 倒算 r；周期股 → 倒算业绩变化曲线。

> 「**倒算可能比正算意义更大。**」倒算出的隐含假设处在合理区间的相对位置，**是比 PE/PB 历史分位数更有效的判断指标**。

**周期股专用映射**（盈利高点 PE 反查隐含天花板，r=10%）：`32倍→6倍`；`10倍→持平`；`7倍→打5折`；`5倍→打3折`。

### 3.4 表征叙事空间的可观测变量

**不是 ROE，也不是当期增速**（书中已证伪：行业 PB-ROE 拟合 R²<0.05；PE 与当年增速无视觉相关性）。

真正有效的是**远期空间的代理指标**（行业专属）：

- 白酒：**批价/出厂价**（提升出厂价 = **兑现**叙事，无超额；批价上行 = **上修**叙事，有超额）
- 光伏：政策文件隐含的**替代/渗透比例**
- 周期股：盈利高点 **PE 反查隐含天花板**
- 宏观：隐含 ERP vs 财新 PMI（PMI 是**一阶导**，只有边际变化才引起 ERP 变化）
- 跨行业唯一通用：**`个股PE(TTM) / 宽基PE(TTM)`**（相对天花板指标）

### 3.5 叙事三阶段模板

**叙事展望期 → 叙事兑现期 → 新一轮展望期**

- **判定分割法**：变换个股与宽基累计涨跌幅的起始点位，**重合**区间=兑现期，**分离**区间=变化期。
- 展望期：涨幅一次性透支（乐观资金线性外推打到"能自圆其说的上限"），业绩尚未兑现。
- 兑现期：股价与宽基重合，持有期收益率 = r；**业绩再高增长也不产生超额收益**。
- 拔估值两阶段：前半段"横着拔"（上修 m，涨幅不回吐）→ 后半段"竖着拔"（降 r，均值回归，**必回吐**，走"A"形）。
- 政策驱动型"三关"（煤炭复盘）：①供给约束→涨价；②需求跟进→业绩释放；③资本开支约束→真金白银分红。每过一关上一个台阶，**证伪即跌回**。

## 四、第 2 步 · 引擎 B：三表科目级验证

### 4.1 三表定位

| 报表 | 性质 | 角色 | 关键动作 |
|---|---|---|---|
| 资产负债表 | 存量表（事实） | **主角** | 找"家底"、找造假落点、找调节痕迹 |
| 利润表 | 流量表（意见） | 被验证对象 | 拆季度、看增速真实性、看非经常性损益占比 |
| 现金流量表 | 流量表（证词） | 辅助验证 | CFO/净利、收现比、自由现金流 |

### 4.2 资产负债表扫描顺序（9 项）

1. **生产类资产**（固定资产 + 在建工程 + 无形资产 + 使用权资产）：最实的部分，看周转率趋势
2. **营运资本**（应收 / 存货 / 预付 / 合同资产）：看周转率与毛利率是否背离
3. **金融类资产**（货币资金）：**存贷双高检测 + 利率倒算**
4. **商誉 + 无形资产**：最虚的部分，看商誉/累计归母、减值节奏
5. **递延所得税资产 + 负债**：**万能探测器**（见模块 D）
6. **少数股东权益 + 损益**：判断"归母"是否失真
7. **有息负债结构**：短期借款 / 一年内到期 / 长期借款 / 应付债券 / 租赁负债
8. **永续债 / 优先股**：**归母口径陷阱**（实为负债却计入权益）
9. **合同负债**：预收款，收入的先行指标

### 4.3 利润表验证

- 季度归母拆分（识别"业绩反转前夜一把减到底"）
- 营收季度拆分（识别增长是否加速/失速）
- 扣非归母 vs 归母（非经常性损益占比）
- 毛利率趋势 vs 存货周转率趋势（是否背离）

### 4.4 现金流量表验证

- **CFO / 归母净利**（>1 为好，连续 <0.7 为红旗）
- **收现比** = 销售商品提供劳务收到的现金 / 营业收入（<1 为红旗；关联 1.13 增值税口径）
- **自由现金流** = CFO − 购建固定资产等长期资产支付的现金
- 投资/筹资现金流：资本开支节奏、分红、定增、还债

## 五、第 3 步 · 模块 C：舞弊识别（合理怀疑 + 有罪推定）

### 5.1 七类舞弊与落点

| 类型 | 落点科目 | 核心识别信号 |
|---|---|---|
| **收入舞弊** | 应收账款 → 存货/预付/其他应收 → 在建工程/固定资产 | **应收账款周转率断崖下降 + 毛利率上升**（背离） |
| **成本舞弊** | 存货、应付账款、在建工程 | 存货周转率异常上升、固定资产周转率下降 |
| **货币资金舞弊** | 货币资金 | **存贷双高 + 倒算存款利率 <1%**；母公司报表利率更异常 |
| **商誉舞弊** | 商誉 | 商誉/累计归母过高、减值节奏可疑 |
| **投资收益舞弊** | 长期股权投资、投资收益 | 投资收益/利润总额过高、来源不明 |
| **关联交易** | 其他应收、预付、长期股权投资 | 关联收入骤升 + 应收挂账 |
| **审计信号** | — | 非标准无保留意见、变更会计师事务所 |

### 5.2 造假落点的进化路径（越往后越难查）

```
应收账款（不涉及现金，最简陋）
  → 存货 / 预付账款 / 合同资产 / 其他应收（需现金流配合）
    → 在建工程 / 固定资产 / 无形资产 / 长期股权投资 / 商誉（需虚构项目、注册子公司、产权交割）
```

**逆向思考原则**：专门看**存量金额大**的、**冷门**的科目。
2020 年后收入舞弊已从"无中生有"升级为**真实客户配合的"真假混合"**，传统从供应商入手的手段已失效。

### 5.3 舞弊评级

- **A 级（低嫌疑）**：红旗 0 条，标准无保留意见
- **B 级（中）**：红旗 1~2 条，均可给出合理解释
- **C 级（高）**：红旗 3~4 条，或存在无法解释的科目异动
- **D 级（重大）**：红旗 ≥5 条，或审计非标，或存贷双高 + 利率倒算异常 → **直接远离，不估值**

## 六、第 4 步 · 模块 D：合法调节识别（小心公司预判你的预判）

### 6.1 万能探测器：递延所得税（二阶导）

> 「税务局帮助我们一次性筛选出了所有『只有会计报表认可、税务报表不认可』的财务调节手段。」

**判据**：正常情况下，递延所得税资产/负债的**增加值与营业收入或净利润的比值**应保持大致稳定。

- **二阶导为正**（加速增加）= 公司**超额计提费用压利润** → 行业格局往往较好，是好事
- **二阶导为负**（冲回）= **放利润** → 虽然利润增速仍在甚至加速，但**已是强弩之末**

**必须剔除的明细项**：未弥补亏损、会计直线/税务加速折旧、未实现内部交易损益。

### 6.2 调节手法清单

| 环节 | 手法 | 排查要点 |
|---|---|---|
| **收入** | 提前确认 / 一次卖不干净的交易（返利、积分、试生产、资产交换、分期模糊） | 合同负债变化、预提费用蓄水池 |
| **成本** | 成本 vs 期间费用划分模糊；存货调节支出资本化比例 | 毛利率异常平稳 |
| **折旧摊销** | 折旧年限/方法变更 | 固定资产周转率突变 |
| **费用计提** | 售后保修、职工薪酬跨期、股权激励、盘盈盘亏 | 销售费用率/管理费用率突变 |
| **财务费用** | 利息支出**资本化**；摊余成本法 | 资本化利息/净利润 |
| **其他收益** | 政府补助不规范确认 | 其他收益/利润总额 |
| **投资收益** | 边际定价重估、计量方式转换（成本法→权益法→公允价值） | 投资收益/利润总额 |
| **减值** | **业绩反转前夜一把减到底** | 单季巨额亏损 + 后续低折旧基数 |

### 6.3 调节评级

同舞弊评级 4 档（A/B/C/D），但语义不同：**A=报表干净，D=报表被重度修饰（虽合法，但不可信）**。

## 七、第 5 步 · 叙事匹配度打分卡

| 维度 | 权重 | 打分依据 |
|---|---|---|
| **叙事清晰度** | 20% | 能否用一句话说清"市场在赌什么"；隐含 L 是否可测算 |
| **财报兑现度** | 25% | 引擎 B：营收/利润/现金流三者是否共振向上 |
| **财务可信度** | 30% | 模块 C + D 的评级（D 级直接否决） |
| **估值安全边际** | 15% | 隐含 L 与历史/合理中枢的距离 |
| **叙事可持续性** | 10% | 是否处于"竖着拔"后半段；是否有证伪信号 |

**总分 → 结论映射**

- **80~100**：叙事成立且被财报兑现，可跟踪
- **60~79**：叙事成立但有瑕疵，需盯开放项
- **40~59**：叙事与财报背离，谨慎
- **<40 或 C/D 任一为 D 级**：叙事已被证伪或财报不可信 → **远离**

## 八、执行纪律（金句即规则）

1. 「**决定股价涨跌的是叙事而非业绩。**」
2. 「**业绩的增长弥补不了估值的下跌。**」
3. 「**便宜是硬道理，便宜意味着预期低，超预期的可能性就高；在给定终点的情况下，起点决定涨幅。**」
4. 「**大前提——沉没成本不影响未来决策；小前提——ROE 的分母是沉没成本；结论——ROE 不影响未来股价走势。**」
5. 「**公司压利润的时候，行业格局往往较好；放利润的时候，利润增速仍在甚至加速，但已是强弩之末。**」
6. 「**优质并不会带来超额收益，带来超额收益的只有『低估』。**」
7. 「PE 的历史分位数没有意义——只要公司存在一天，PE 就应该下降一天，合理分位数就应该是 0。」
8. 「**应然与实然必须严格区分。**」
9. 存贷双高的公司：**长年累月持有巨额现金，要么是现金有问题，要么是融资能力存在重大不确定性，估值需要深度折价。**
10. 商誉与投资收益舞弊：**没有十足把握时，谨慎处理＝直接打折估值。**
